# HOE — Heaven On Earth

Repository for developing the Heaven On Earth application.

## Project status

- Development branch: `main`
- Intended staging domain: `hoe.dating`
- Hosting provider: Hostinger
- Hosting connection: pending setup and verification
- Application implementation: not started; framework and backend to be selected before development

This repository is the source-control foundation for the application. Hostinger deployment instructions are in [HOSTING.md](HOSTING.md).

## Development

Create feature branches and use pull requests for review before merging to `main`. Select the application architecture after confirming the Hostinger hosting type and the app requirements.

## Configuration

Keep account credentials, API keys, database passwords and production environment files outside Git. Commit only documented placeholder values in `.env.example` when configuration is introduced.

## Existing website

The staging target is `hoe.dating`. Setting up this repository does not change `heavenonearth.app`.
